# Personalized Outfit Set Recommendation journey v1

Status: fixture-only, default-off, deterministic, unlinked, and `noindex`.

## Purpose

The route makes owned-first, diversity-aware outfit-set selection reviewable
before any real profile, wardrobe, website, app, extension, or AI Stylist
integration.

## Route and modes

- Route: `outfit-set-fixture.dc.html?ww_outfit_set=1`
- Complete two-outfit set.
- Complete three-outfit set.
- Owned-first preference inside a comparable quality band.
- Duplicate-formula exclusion.
- Exact tie crossing the selection boundary.
- Insufficient trustworthy candidates.
- No qualified candidates.
- Stale product-evidence exclusion.

Changing evidence clears the prior result. Reset restores the deterministic
default and keyboard focus.

## Visible evidence

The page renders selected, tied, and qualified IDs; desired count; decision
reasons; trust thresholds; and every candidate's compatibility score, evidence
coverage, confidence, ownership counts, five-part formula, exclusion or
qualification reasons, and accepted compatibility-result reference.

## Safety boundary

The page delegates every recommendation to the accepted Outfit Set contract.
It stores nothing and performs no profile or wardrobe access, network,
analytics, tracking, account, affiliate, retailer, purchase, or external
action. Private behavior, prices, commission, popularity, and credentials are
absent.

# Style DNA journey v1

Status: fixture-only, default-off, deterministic, unlinked, and `noindex`.

## Purpose

The route makes the accepted Style DNA contract understandable before any real
account, collection, persistence, app, or extension integration exists. It
shows that a useful style profile can remain editable and explainable rather
than becoming hidden identity.

## Route and review modes

- Route: `style-dna-fixture.dc.html?ww_style_dna=1`
- Explicit and accepted inferred signals.
- Explicit choice versus contradictory inference.
- Accepted inference after deterministic confidence decay.
- Stale and low-confidence inference exclusion.
- Explicit correction replacing inference.
- Later correction removing an earlier signal.
- Temporary exploration separate from canonical Style DNA.

Changing the evidence state clears the prior result. Reset restores the
deterministic default and keyboard focus.

## Visible result

The page renders only:

- canonical dimension/value signals;
- positive or negative sentiment;
- explicit, inferred, or correction provenance;
- confidence, confidence band, and allowlisted evidence codes;
- accepted, low-confidence, and stale inference counts;
- conflicts requiring user review;
- temporary exploration and its non-canonical status; and
- fixed user-control policy.

## Safety boundary

The fixture stores nothing and performs no behavior collection, network,
analytics, tracking, account, affiliate, retailer, purchase, or external
action. It accepts no real profile or wardrobe and renders no raw wardrobe,
browsing, shopping, purchase, return, private note, account, protected
attribute, price, commission, popularity, or credential data.
